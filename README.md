# 出海招标雷达

按行业、采购方所在地、服务目标区域检索跨境法律与咨询服务采购信息。支持关键词搜索、来源证据筛选、截止状态、排序、浏览器收藏、分享筛选链接、CSV 导出和手机阅读。

## 数据

`data/tenders.json` 为唯一发布数据源。首期观察窗口为 2026-07-10 至 2026-10-10；15 条采购信息，1 条独立待核验线索。公开网络检索样本不代表全网完整覆盖。官方来源、转载、信息不完整分别标注。未知字段保持未知；不把发行规模写成预算、不把采购所在地推定成服务国别。

`meta.updatedAt` 仅在完成真实检索与核验后更新。`nextPlannedUpdate` 为计划日期，未按期完成时页面自动显示逾期提示。截止状态按北京时间计算；只披露日期时注明时刻待核验。报名与响应截止是不同时间，请阅读原公告。

## 更新机制

通过当前 Codex 聊天的每 5 天自动任务执行：多搜索引擎与官方源检索、读取公告、去重、证据核验、更新 JSON 并发布到本仓库。任务在本机 Codex 中运行，依赖本机可运行状态、网络和 GitHub 连接；不是 GitHub Actions 内置联网检索。GitHub Pages 在 main 分支提交后自动重新发布。失败不伪造最近更新时间，通知用户处理。

更新时按当地日期向前取三个日历月，将旧公告移入 `data/archive/`，滚动窗口保留相关采购、结果与变更（同一项目标包关联，不重复统计）。摘要来源与核验日期随条目记录，待核验线索独立展示。

## 本机预览及校验

```sh
python3 -m http.server 8765 --bind 127.0.0.1
python3 scripts/validate.py
node --check app.js
```

GitHub Pages：Settings → Pages → Deploy from a branch → main / root。

## 文件边界

只有本项目目录里的网站文件与公开信息上传；不读取或发布父目录里的个人材料或凭据。纯静态网站，无登录、无跟踪服务、无付费依赖。收藏仅存于访问者当前浏览器。
