# 公开信息来源与扩源逻辑

研究及实施日期：2026-10-10。观察窗口：2026-07-10—2026-10-10。

## 竞品公开资料能证明什么

本轮以公开可检索的律采标讯、律讯网及其转载公告为样本。“律易采”小程序内部未访问，不能确认其完整数据集、私有供稿渠道或技术架构，也无法量化本站是否超过其总覆盖量。

[律讯网官方介绍](http://www.lvxunlaw.com/about/p/index)称：其与采购业主、招标公司、企业单位合作；律采标讯2022年开发、2023年初上线；信息基础包括政府资源、行业协会、招标代理和业主合作；还提供专业整理和定制匹配。这是平台自述，不是我们对其覆盖率的独立认证。官方没有公开具体爬虫、供应商或API清单。

可观察到的逻辑：汇集不同采购渠道 → 法律关键词与地区分类 → 关联招标、变更、结果、前期需求 → 订阅与会员服务。批量抓取、搜索发现加编辑核验是可行实现推断，不能当作其已披露技术事实。

原发布渠道通常写在公告中。例如[进出口银行山东境外清盘项目](http://www.eximbank.gov.cn/info/notice/jzcg/202610/t20261008_78182.html)列出公共服务平台、金采网、代理官网、银行官网；[新诺佳IPO重发公告](https://www.nbgodo.com/info.aspx?id=16875&chid=11)列出公共服务平台、乐采云、代理及采购人官网。因此一个项目可能被多个聚合平台重复收录；更多网址不等于更多独立采购。

## 本站已实施的扩源

1. 登记29个渠道，分政府公共资源、金融及海外子公司、企业采购、代理行业、专业平台、国际机构六组；记录已读取、读取受限、需动态读取、待接入。
2. 首轮关键词扩成14个检索主题，不只查“境外法律”：还查海外追偿、IPO、投资国别、财税、数据出境、制裁、贸易救济、知识产权和伙伴招募。
3. 用TinyFish搜索、每批最多10个URL的公开页面读取及PDF抽取，核验银行原文、代理原文、海外子公司PDF等。
4. 新增10条：7条采购/招募、3条结果；总计25条收录、5条线索。新增项目不是都比竞品独有，其中部分就是由竞品公开周报发现后反查。
5. 新增robots-aware低频候选发现脚本、域名检索矩阵和HTML导入接口。脚本不自动发布候选。每5天任务需逐条核验并保存渠道运行摘要。

## 窗口、分类与去重

结果披露、合作伙伴招募和前期询价分别标注；结果不当作报名机会。报名/文件获取和响应截止分别展示。相同采购编号按标包关联变更与结果，重发标包不与已中标其他标包混淆。采购方地区与服务法域独立；海外子公司的所在地不意味着服务范围只有当地。

检索既看标题也看全文，避免常年顾问采购正文包含跨境服务却被标题规则遗漏。普通国内法律、工程商品、旅游和个人招聘排除；相关综合项目需说明跨境部分与整个项目预算口径。国际机构只收相关法律、贸易投资及企业出海咨询。

## 持续运行与边界

先robots允许的公开页面 → 动态读取 → 搜索引擎域名检索 → 代理或业主原文 → 转载证据降级。HTTP原文保持实际链接，不把失败的HTTPS地址冒充可用原文。超时、验证码、会员页和动态空壳需保留失败状态，不能伪造成功日期。

当前更新为本机Codex每5天任务，依赖本机运行与网络。GitHub Pages只发布静态网站，不自行联网抓取。新增公开频道会持续补充；29个登记渠道不是29个已完整爬取数据库。没有购买竞品或绕过其登录限制。
